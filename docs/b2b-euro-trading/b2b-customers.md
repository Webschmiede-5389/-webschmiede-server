# B2B-Kunden finden (Wholesale) – jenseits Marktplätze

Stand: Juli 2026  
Ergänzung zu Händler-Radar (Marketplaces). Hier: **wer kauft deine Ware ein**, nicht nur wer sie online weiterverkauft.

## 1. Klassische B2B-Verzeichnisse / RFQ

| Quelle | Was du tust | Fit |
|--------|-------------|-----|
| **wlw (Wer liefert was)** | Als Lieferant listen + **Anfragenportal** (Einkäufer suchen aktiv) | Hoch DACH |
| **Europages** | EU-Profil, Einkäuferanfragen beantworten | Hoch EU-Export |
| **Mercateo / Unite** | B2B-Beschaffung, oft Büro/Industrie | Mittel (Sortiment) |
| **Wonnda** | Private Label / Hersteller-Suche (andere Seite) | eher wenn du fertigst |

Trick: Nicht nur „gefunden werden“. Täglich Anfragen öffnen und antworten.

## 2. Wholesale-Marktplätze (Retailer kommen zu dir)

| Plattform | Zielkunde | Fit |
|-----------|-----------|-----|
| **Ankorstore** | Unabhängige Läden EU | Hoch Lifestyle/Beauty/Home |
| **Orderchamp** | Boutiquen, Home, Beauty | Hoch |
| **Faire** | Independent Retail global/EU | Hoch |
| **Creoate** | UK + EU, nachhaltiger Mix | Mittel |

Du listest Konditionen/MOQ. Retailer bestellt. Weniger Kaltakquise, mehr Plattform-Gebühr.

## 3. Online-Händler (bereits im Radar)

Idealo/Kaufland/MMS/OTTO/Temu Local → Impressum → Wholesale-Mail.  
Das bleibt der **skalierbare Scanner-Pfad**.

## 4. Stationär + Hybrid

| Quelle | Idee |
|--------|------|
| **Gelbe Seiten / Branchenbuch** | „Elektronikfachhandel“, „Drogerie“, „Parfümerie“ regional |
| **IHK-Mitgliederverzeichnisse** | Region + Branche Handel |
| **Handelsverband / BGA** | Verbandsmitglieder, Events |
| **Filialketten Einkauf** | Zentrale Einkaufsabteilung (schwer, aber groß) |
| **Franchise-Systeme** | Franchise-Zentrale statt Einzelladen |

## 5. Messen (hohe Abschlussquote)

Ambiente, Ambiente Frankfurt, Tendence, Beauty-Messen, CEBIT-Nachfolger/Fachmessen Elektronik, regionale Ordermessen, TrendSet.  
Vorher: Ausstellerliste + Besucher-App → Leads mit Freigabe anrufen.

## 6. LinkedIn / Sales Navigator

Filter z. B.:

- Titel: Einkauf, Procurement, Category Manager, Inhaber Onlinehandel  
- Branche: Wholesale, Retail, E-Commerce, Consumer Electronics  
- Größe: 2–200 MA (oft entscheidungsfreudig)  
- Land: DE + Nachbarn  

Kein Massen-Spam. Kurz + Sortiment + MOQ. Passt zu Freigabe-Logik.

## 7. Reverse Demand (sie suchen Lieferanten)

| Signal | Wo |
|--------|-----|
| „Lieferant gesucht Oral-B / Aufsteckbürsten“ | Kleinanzeigen Gewerbe, sellerforum, Facebook-Gruppen Händler |
| Ausschreibungen / RFQ | wlw Connect, Europages Anfragen |
| Nachfolger übernimmt Shop | nexxt-change (braucht neuen Lieferantenstamm) |
| Neuer Temu/Kaufland-Seller | Emerging → oft noch kein stabiler Einkauf |

## 8. Partner-Kanäle

- **Dropship-/Fulfillment-Partner** die Händler anbinden  
- **ERP/Multichannel-Agenturen** (JTL, Afterbuy-Partner) → White-Label-Empfehlung an deren Kunden  
- **Steuerberater/Gründerzentren** für neue Online-Shops  

## Priorität für Start (praktisch)

1. Idealo/Kaufland-Händler-Radar (scannbar)  
2. Ankorstore/Faire/Orderchamp (wenn Sortiment passt)  
3. wlw + Europages Anfragenportal  
4. LinkedIn gezielt (10–20/Woche, nicht 500)  
5. 1–2 Messen/Jahr mit Vorarbeit  

## Abgrenzung

| Pfad | Kunde | Automatisierbar? |
|------|-------|------------------|

| Wholesale-Plattform | Boutique/Laden | teils |
| wlw/Europages | Industrie/Handel Einkauf | teils |
| LinkedIn/Messe | Entscheider | eher manuell |
