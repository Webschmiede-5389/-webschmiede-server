# Vertrags-Checkliste (Webschmiede)

Jede Prüfung: jede Zeile mit ✅ / ⚠️ / ❌ / n.a. markieren. Leer = Prüfung unvollständig.

## A – Haftung & Risiko

| ID | Prüfpunkt |
|----|-----------|
| A1 | Haftung der Höhe nach begrenzt (soweit gesetzlich zulässig)? |
| A2 | Ausschluss/Begrenzung für indirekte Schäden / entgangenen Gewinn klar? |
| A3 | Keine unzulässige Freizeichnung bei Vorsatz / grober Fahrlässigkeit / Körperverletzung? |
| A4 | Drittanbieter-APIs (Meta, Keepa, Lexware, Stripe, …): Ausfall/Fehler nicht pauschal bei Webschmiede? |
| A5 | Gewährleistung / Mängel: Fristen und Mitwirkung Kunde klar? |
| A6 | Freistellung bei Kundeninhalten / rechtswidrigen Vorgaben des Kunden? |
| A7 | Versicherung / Höchstbetrag erwähnt nur wenn sinnvoll, nicht widersprüchlich? |

## B – Datenschutz & AVV

| ID | Prüfpunkt |
|----|-----------|
| B1 | Bei personenbezogenen Daten: AVV nach Art. 28 vorhanden oder angehängt? |
| B2 | Gegenstand, Art, Zweck, Dauer der Verarbeitung beschrieben? |
| B3 | TOMs (Verschlüsselung TLS, Zugang, Backup, Logging) konkret genug? |
| B4 | Speicherort EU/DE (Hetzner) genannt und stimmig mit Realität? |
| B5 | Unterauftragsverarbeiter gelistet / Änderungsprozess? |
| B6 | Löschung / Rückgabe / Retention (keine ewige Speicherung ohne Grund)? |
| B7 | Keine Pflicht zu unsicheren Kanälen (z. B. unverschlüsselte WhatsApp-Pflicht) ohne Alternative? |
| B8 | Betroffenenrechte / Unterstützung bei Auskunftsansprüchen erwähnt? |

## C – Geld & Vertragslauf

| ID | Prüfpunkt |
|----|-----------|
| C1 | Setup- und Monatspreis / Einmalprojekt klar und netto/brutto? |
| C2 | Zahlungsziel und Mahnung / Verzug geregelt? |
| C3 | Laufzeit und ordentliche Kündigung (Frist) klar? |
| C4 | Auto-Verlängerung transparent (wenn ja: Hinweis + Kündigungsfenster)? |
| C5 | Preisanpassung / Index nur mit Ankündigung und Ausstieg? |
| C6 | Was passiert bei Nichtzahlung (Suspendierung Service) – verhältnismäßig? |
| C7 | Reisekosten / Extra-Aufwand / Change Requests geregelt? |

## D – Leistung & Formalia

| ID | Prüfpunkt |
|----|-----------|
| D1 | Leistungsgegenstand konkret (Portal, Automation, Dashboard, …), kein leeres Buzzword? |
| D2 | Mitwirkungspflichten Kunde (Zugänge, Inhalte, Freigaben) klar? |
| D3 | Support-Zeiten / Reaktionszeiten nur wenn zugesagt, sonst kein Fake-SLA? |
| D4 | Nutzungsrechte / Code / Design: wer besitzt was nach Zahlung? |
| D5 | Geheimhaltung / NDA: Dauer und Ausnahmen (gesetzliche Pflichten) ok? |
| D6 | Keine widersprüchlichen Klauseln zwischen Angebot, Auftrag, AGB, AVV? |
| D7 | Vertragsparteien, Adressen, Vertretung, Datum, Unterschriftfelder vollständig? |
| D8 | Gerichtsstand / anwendbares Recht (DE) und B2B-Kontext stimmig? |
| D9 | Anlagen (AGB, AVV, Leistungsbeschreibung) referenziert und vorhanden? |

## Schnellfilter Fremdvertrag (Kunde liefert Text)

| ID | Prüfpunkt |
|----|-----------|
| F1 | Einseitige IP-Übertragung „alles an Kunde“ ohne Lizenzrest? |
| F2 | Unbegrenzte Haftung für Webschmiede? |
| F3 | Wettbewerbsverbot / Abwerbeverbot unverhältnismäßig? |
| F4 | Audit-Rechte ohne Grenzen / Vorankündigung? |
| F5 | Pflicht zu Tools/Standorten außerhalb EU ohne AVV? |
