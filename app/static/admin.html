Live-Pfad: Drucker am PC

Am Tresen-PC angeschlossen. Option A = Button auf der Bestellkarte. Option B = Autoprint-Skript druckt automatisch auf denselben Windows-Drucker. Extra Küchen-Netzwerkdrucker ist nicht nötig.

Option A – Drucken-Button (sofort nutzbar)
🖨️
Sofort aktiv – kein Setup
Browser-Druck
Jede Bestellkarte hat einen blauen "Drucken"-Button. Klick darauf öffnet den Windows-Druckdialog. Funktioniert mit jedem Drucker der am PC angeschlossen ist.
Option B – Auto-Druck (PC-Hintergrunddienst)
💻
Automatisch – druckt ohne Klick
autoprint.py – läuft im Hintergrund
Skript läuft auf Hassans PC. Neue Bestellungen werden automatisch gedruckt sobald sie eingehen. Kein Klick nötig.
1
Python installieren: python.org/downloads → "Install Now"
2
Terminal öffnen (Win + R → cmd) und eingeben:
pip install requests pywin32
3
Datei autoprint.py herunterladen und auf Hassans Desktop legen.
4
Drucker-Name in der Datei eintragen (Zeile PRINTER_NAME). Den Namen findest du unter Windows → Drucker & Scanner.
5
Skript starten:
python autoprint.py
6
Autostart: Win + R → shell:startup → Verknüpfung zur Datei dort ablegen. Startet dann automatisch mit Windows.
Option C – Netzwerk-Bondrucker (Profi-Lösung)
🏪
Optional – nicht nötig wenn PC-Drucker läuft
ESC/POS Bondrucker via WLAN/LAN
Nur wenn später ein eigener Netzwerk-Bondrucker kommt. Aktuell reicht der Drucker am PC (Option A oder B).
Empfohlene Drucker:
Epson TM-T20III
ca. 150 €
USB + Ethernet · Einstieg
Star TSP143IIILAN
ca. 180 €
Ethernet + WLAN · Profi
Epson TM-T88VII
ca. 250 €
USB + WLAN + BT · Premium
1
Drucker per LAN-Kabel oder WLAN mit dem Router verbinden
2
IP-Adresse des Druckers herausfinden (meist 192.168.1.xxx – steht im Router oder im Drucker-Menü)
3
In autoprint.py eintragen:
PRINT_MODE = "escpos"
PRINTER_IP = "192.168.1.100"
PRINTER_PORT= 9100
4
Fertig – ab sofort druckt die Küche automatisch bei jeder neuen Bestellung
