# B2B Euro Trading / Händler-Radar

Stand: Juli 2026  
Ziel: Wholesale-Leads für Multichannel-Händler in DE/EU finden und (mit Freigabe) Angebote senden.

## Produkt in einem Satz

**Produkt/EAN → scannbare Märkte → Händler → Impressum → Multi-Channel-Nachweis → Score → Freigabe → Wholesale-Angebot.**

Nicht Amazon knacken. Die mittleren Marktplätze und Preisvergleiche nutzen, Amazon/eBay nur zur Anreicherung.

## Zwei Geschäftsmodelle

1. **Eigenes Wholesale** (du verkaufst Ware an Händler)  
2. **Software/Radar verkaufen** an Großhändler (wie Akquise-Krieger, nur E-Com)

Gleiche Bausteine wie Akquise: Quellenkatalog, leichter Scan, Enrichment, Freigabe, kein Blind-Spam (UWG).

## Nächster technischer Schritt (wenn freigegeben)

1. Pilot: eine Marke/EAN (z. B. Oral-B Aufsteckbürste)  
2. Quellen: Idealo + Kaufland + OTTO + MediaMarkt (leicht)  
3. Impressum-Parser + Multi-Channel-Score  
4. Freigabe-UI (wie `akquise-freigabe.html`)
