# Icon System

**Datei:** `config/ui_icons.yaml`

## Entscheidung

Eine Bibliothek für interne Apps: **Font Awesome 6** (bereits Agency Cockpit / Hub).

- Keine Emoji-Nav
- Dekorative Icons: `aria-hidden="true"`
- Externe Dienste: Vendor-Logo optional auf ToolCard, nicht als globales Icon-Set
