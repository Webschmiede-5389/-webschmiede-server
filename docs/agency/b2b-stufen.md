# B2B-Stufen Webschmiede (Empfehlung)

Stand: 2026-07-18  
Canvas: `b2b-stufen-vergleich` (neben dem Chat)

## Beschluss-Empfehlung

**Nicht** sieben Einzelpreise (1k / 1,5k / 2,5k / 3,5k / 4,5k / 5k / 6k).  
**Stattdessen:** 4 feste Stufen **1.000 → 1.500 → 2.500 → 3.500 €/Monat**, darüber **Optionen** bis 6.000 €.

Lokal-Pakete (Gastro/Handwerk ca. 248–698 €) bleiben parallel für kleine Betriebe.

## Die 4 Stufen (netto)

| Stufe | Monat | Setup ca. | Kern |
|-------|------:|----------:|------|
| Betrieb | 1.000 € | 2–4k | Portal/Website, Hosting, CRM-Basis, Support |
| System | 1.500 € | 3–6k | + SMS/WA, Follow-ups, Bewertungs-Funnel |
| Automatik+ | 2.500 € | 5–10k | + Buchhaltungs-Pipeline, Reports, engere SLA |
| Partner | 3.500 € | 8–15k | + Integrationen, Voice opt., fester Ansprechpartner |

Fremdkosten (SMS-Cent, Retell, Domains, Ads-Budget) immer separat.

## Optionen (ab Automatik+ / Partner)

| Option | Aufschlag / Monat |
|--------|------------------:|
| Zweiter Standort / Marke | +800–1.200 € |
| Ads light (Google/Meta) | +800–1.500 € |
| Voice Produktion + Nummer | +400–900 € |
| Buchhaltung tief (Silo/Lexware) | +400–700 € |
| Prioritäts-SLA (&lt; 4h Werktag) | +500 € |

Partner + 2–3 Optionen = **5.000–6.000 €** ohne neuen „Stufe-6-Namen“.

## Vergleich große Agentur vs. wir

| | Große Agentur | Webschmiede |
|--|---------------|-------------|
| Monat | oft 3–8k nur Marketing oder Projekt 20–80k | 1–3,5k System inkl. Betrieb |
| Angebot | Stunden, Kampagnen, PDFs | Laufendes Betriebssystem |
| Stack | HubSpot / Salesforce / GHL | eigene Engine, kein GHL |
| Tempo | lange Kickoffs | Branchen-Templates, schneller Live |
| Kai Stone | 200–300 $ Volumen-SaaS | höheres Ticket, weniger Kunden, mehr Tiefe |

## Verkauf

Immer Outcome: Anfrage rein → sofort Nachricht → Job in der Liste → Beleg zum Steuerberater → Handy summt.  
Im Call nur die 4 Stufen. Optionen erst wenn Partner passt.
