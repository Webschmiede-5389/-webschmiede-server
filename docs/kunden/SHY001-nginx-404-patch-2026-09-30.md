# SHY001 – Nginx Soft-404 Korrektur (Vorschlag, noch nicht live)

Stand: 2026-09-30. **Nicht deployed.** Aktive Live-Datei:
`/etc/nginx/sites-enabled/snackhouse-yassine.de`

## Ist

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

Unbekannte URLs (z. B. `/dieser-pfad-existiert-nicht-xyz999`) liefern HTTP 200 + Startseite.

## Soll (kleinste sinnvolle Änderung)

```nginx
location / {
    try_files $uri $uri/ =404;
}
```

Explizite Routen bleiben unverändert:

- `location = /bestellen` → `order.html`
- `location = /admin`, `/konto`, Legal, `/agb`
- `location /api/` → Gunicorn `:8001`
- `location /uploads/` → proxy
