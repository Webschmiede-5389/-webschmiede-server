# Hetzner AV-Vertrag (Auftragsverarbeitung)

Stand: 2026-07-19

## Warum

Webschmiede hostet Kundendaten auf Hetzner Cloud. Dafür braucht ihr den **AV-Vertrag mit Hetzner** in den Akten (Art. 28 DSGVO, Unterauftragsverarbeiter).

## Wahrheit Standort

Live: **Deutschland, Nürnberg** (web-01neu).  
Nicht mehr behaupten: Helsinki/Finnland als Live-Standort.

## Ablauf (Christian, 5 Minuten)

1. Einloggen: https://console.hetzner.cloud/
2. Account / Security / **Legal** bzw. Suche nach **Data Processing Agreement** / **Auftragsverarbeitung**
3. AVV akzeptieren falls noch offen, PDF herunterladen
4. Ablegen lokal unter z. B. `docs/agency/vertraege/akten/hetzner-avv.pdf` (nicht committen wenn unerwünscht) und/oder in der Buchhaltungsablage
5. Datum im Memory notieren: `docs/memory/topics/enterprise-dsgvo.md`

Offizielle Hilfe oft unter: Hetzner Docs „Data Processing Agreement“ / Cloud Console Legal.

## Was Nils nicht macht

Kein automatisches Akzeptieren von Verträgen ohne dein OK. Keine Fake-PDFs erzeugen.

## Bezug Kunde

Gegenüber dem **Kunden** gilt zusätzlich unser DocuSeal-AVV (`WS AVV` / Kundenpaket), nicht der Hetzner-AV allein.
