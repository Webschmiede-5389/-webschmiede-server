Digitale Handwerkskunst

Voice Demo

Stimme = Klang. Stil = Wortlaut (z. B. Kölsch). Branche wählen, tippen, sprechen, nochmal tippen.

Lade Auswahl…
Bereit. Einmal tippen = starten, nochmal tippen = senden.

Mikrofon braucht HTTPS: digitalehandwerkskunst.de/voice-demo/ (nicht die nackte IP). Hard-Refresh: Strg+F5. Stimme ändert den Klang, Stil den Text. Dialekt-Aussprache bleibt TTS-Hochdeutsch, der Wortlaut folgt dem Stil.
